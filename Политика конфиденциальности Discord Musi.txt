Политика конфиденциальности Discord Catnip Radio

Дата вступления в силу: 15 октября 2026 г.
Оператор бота: Green_Tea
Контакт для вопросов по конфиденциальности: r36246146@gmail.com

1. Общая информация

Эта политика описывает, какие данные обрабатывает Discord Music Bot («Бот») и для каких целей. Бот предназначен для управления воспроизведением музыки в голосовых каналах Discord.

2. Какие данные обрабатываются

При использовании команд Бот обрабатывает данные, необходимые для их выполнения, в том числе:
- идентификаторы Discord-сервера и текстового канала;
- данные взаимодействия с Discord-командой и выбранный пользователем голосовой канал;
- ссылки, переданные в команду воспроизведения;
- название, автора и другие доступные метаданные трека;
- очередь треков и текущий статус воспроизведения.

Бот не запрашивает пароль Discord, не получает доступ к личным сообщениям и не запрашивает доступ к аккаунту Spotify. Если для Spotify настроены официальные API-ключи, Бот использует Spotify Web API для получения метаданных отдельного трека; аудио напрямую из Spotify не передаётся.

3. Цели обработки

Данные используются только для обработки команд, подключения к голосовому каналу, формирования очереди, воспроизведения доступного аудиопотока, отправки сообщений о статусе и диагностики ошибок.

4. Хранение и удаление

Очередь и сведения о текущем воспроизведении хранятся в оперативной памяти процесса Бота, пока они нужны для работы. Они удаляются при завершении трека, очистке очереди, отключении Бота или перезапуске процесса. Бот не использует базу данных для долговременного хранения пользовательских команд или очередей.

Технические журналы запуска и ошибок могут содержать сведения о сервере Discord и типе ошибки. Их хранение зависит от способа запуска Бота и настроек системы, на которой он размещён. Токен Бота не должен включаться в журналы.

Сообщения, отправленные Ботом в Discord, обрабатываются и хранятся Discord в соответствии с правилами и политикой конфиденциальности Discord.

5. Сторонние сервисы

Для обработки команд и голосового соединения используется Discord. Для получения доступных метаданных и аудиопотока может использоваться yt-dlp и соответствующий сайт-источник. При использовании Spotify-ссылки и настроенных API-ключей выполняется запрос к официальному Spotify Web API для получения метаданных трека, после чего Бот может искать возможное соответствие в доступном источнике.

Сторонние сервисы могут обрабатывать запросы в соответствии со своими условиями и политиками конфиденциальности. Бот не обходит DRM, платный доступ, авторизацию или другие технические ограничения.

6. Передача данных

Оператор не продаёт персональные данные и не использует их для рекламы. Данные передаются сервисам, необходимым для работы Бота, как описано выше. Оператор не контролирует обработку данных Discord и сторонними аудиоисточниками.

7. Безопасность

Токен Бота и другие секреты хранятся в конфигурации на сервере оператора и не должны публиковаться. Доступ к устройству и его журналам контролирует оператор.

8. Права пользователей и обращения

Чтобы прекратить использование Бота, можно перестать вызывать его команды, удалить Бота с сервера или попросить администратора сервера отключить его. По вопросам обработки данных, исправления этой политики или другим вопросам свяжитесь с оператором: r36246146@gmail.com.

Если применимое законодательство предоставляет дополнительные права в отношении персональных данных, запрос можно направить по указанному выше контакту.

9. Изменения политики

Оператор может обновлять эту политику. Актуальная версия будет опубликована по той же ссылке. Дата последнего обновления указана в начале документа.
